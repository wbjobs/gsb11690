# 贝塞尔曲线实验室

无构建依赖的静态贝塞尔曲线编辑器，使用 Canvas 2D、Pointer Events、Web Worker 和 IndexedDB。

## 启动

```bash
npm start
```

打开 `http://localhost:5173`。请通过静态服务器访问，因为 Worker 使用 ES Module，不建议直接用 `file://`。

测试：

```bash
npm test
```

## 功能

- 添加、删除、拖动控制点，支持鼠标、触控笔和触摸。
- 任意阶贝塞尔曲线升阶；降阶在可精确时精确保形，否则使用端点约束的最小二乘近似并报告偏差。
- 使用 de Casteljau 分割；同源分割段可精确合并还原，端点相连的非同段可近似合并。
- 对任意 t 求值，显示一阶导、单位切线、有符号/绝对曲率和曲率半径。
- 绘制控制多边形、求值点、切线箭头和曲率圆。
- Web Worker 负责质量采样；拖动中主线程使用低密度折线近似，保持交互流畅。
- IndexedDB 自动保存，失败时降级到 localStorage，再失败仅保留内存状态。
- 撤销/重做最多保留 100 步，支持 `Ctrl/⌘+Z` 与 `Ctrl/⌘+Shift+Z`。
- 控制点输入、拖动和持久化恢复都会执行世界边界钳制或清洗。
- 最高支持 24 阶；高阶或 Worker 不可用时自动降级为折线采样。

## 交互

- 单击曲线：选择曲线。
- 拖动圆点：移动控制点。
- Shift/Ctrl/⌘ 单击：多选曲线，便于合并。
- 添加模式下点击工作区：向当前曲线追加，或新建直线。
- Delete/Backspace：删除当前控制点。
- Alt/Option 单击曲线：在最近参数处分割。
- 空白处拖动：平移；滚轮：缩放。

## 结构

- `src/math.js`：de Casteljau、导数、切线、曲率、升阶/降阶、分割/合并和采样。
- `src/model.js`：文档模型、边界校验、阶数限制、编辑命令和撤销栈。
- `src/renderer.js`：Canvas 坐标系统、曲线、控制多边形和叠加图形渲染。
- `src/worker-bezier.js`：Worker 端自适应/均匀采样。
- `src/storage.js`：IndexedDB 与 localStorage 降级存储。
- `src/app.js`：Pointer Events、命令面板、快捷键、状态编排和持久化调度。
- `tests/`：核心数学与模型命令测试。

## 精度与降级

- 求值和分割统一使用 de Casteljau，分割/合并残差阈值为 `1e-7`。
- 降阶求解小型对称法方程；非精确降阶在状态栏显示最大控制多边形偏差。
- 自适应采样按弦距递归细分并限制深度，防止折线数量无界增长。
- 阶数达到 24 后禁止继续升阶或追加控制点。
- 曲率接近零时将半径显示为无穷；半径过大时不绘制曲率圆，但面板仍显示数值。
